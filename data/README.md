# Data Setup

Use a public credit-default tabular dataset for this study. Keep raw source files out of version control if redistribution terms are unclear.

## Expected local file
`data/credit_default.csv`

The training script expects a binary target column named `default`.

## Recommended source
UCI Credit Card Default dataset or another documented public credit-risk dataset.

## Reproducibility
Record the source URL, access date, original target column, any renamed columns, exclusions, and preprocessing decisions in `docs/methodology.md` before publishing results.
